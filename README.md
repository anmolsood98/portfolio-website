# Personal Portfolio Website

## About

This is my personal portfolio website, built to demonstrate my skills as a front-end developer and help me further my career in web development. I have built simple websites with different features in the past, but with this project I wanted to bring what I have learned together into a complete portfolio that I can continue improving as I work toward becoming a full-time developer.

I built this project using HTML, CSS, and JavaScript to practice and strengthen concepts I had previously learned and apply them in a real project.

## Concepts Practiced

- HTML structure
- CSS selectors and cascade
- Flexbox
- CSS Grid
- Responsive design and media queries
- DOM selection
- Event listeners
- Form validation
- `if / else` statements
- `classList`
- `localStorage`
- Dark / Light mode
- Persistent user preferences

## Features

- Responsive design for desktop and mobile devices
- Dark and light mode theme toggle
- Persistent theme preference using localStorage
- Custom contact form validation using JavaScript
- Responsive layouts built with Flexbox and CSS Grid
- Project showcase with Live Demo and GitHub links

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## What I Learned

Through this project, I strengthened my understanding of the fundamentals of HTML, CSS, JavaScript, and Git. I also learned new skills, such as how to stage and commit changes with Git, push a project to GitHub, and deploy a website using GitHub Pages.

This is my first live website, so learning how to take a project from development to deployment was a new and exciting experience for me. Building this project has made me more confident in my development skills and has increased my interest and enthusiasm for learning.

I plan to continue building projects, learning new technologies, and improving my skills as I work toward becoming a better front-end developer.
